# 模擬店探偵 〜文化祭のお金の事件簿〜

高校生向けの簿記・FP体験ゲームと、その紹介サイトです。
文化祭の模擬店で起きた「お金の事件」を、帳簿の記録から解き明かします。

> お金は消えない。消えるのは記録。

- **遊ぶ**：`play/index.html`（インストール不要・ネットなしでも動きます）
- **紹介サイト**：`index.html`（トップ）／`how-to-play.html`（遊び方）／`learn.html`（学べること）／`faq.html`（よくある質問）／`download.html`（ダウンロード）／`privacy.html`（プライバシーと利用について）
- **オフライン版**：`download/mogiten-tantei.zip`

## 公開（GitHub Pages）

Settings → Pages で「Deploy from a branch」→ ブランチ `main`・フォルダ `/ (root)` を選ぶと、
`https://mogiten-tantei.github.io/` で公開されます。

## プライバシー

個人情報は集めません。探偵名と進み具合は、遊んだ端末のブラウザの中（localStorage）にだけ保存されます。Cookie や解析ツールは使っていません。

## 制作について

ゲームとサイトの画像・文章・プログラムは、生成AIとの共同作業で作りました。
